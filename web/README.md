# 資産運用シミュレーター Web アプリケーション

TypeScript + React で構築された株式と債券のポートフォリオ管理・シミュレーション Web アプリケーション

## 特徴

- 📈 **株式モデル**: 幾何ブラウン運動による価格シミュレーション
- 📊 **債券モデル**: 現在価値法による価格計算
- 💼 **ポートフォリオ管理**: 資産の購入・売却、リアルタイム資産配分
- 🎲 **シミュレーション**: 単一シミュレーションとモンテカルロシミュレーション
- 📉 **リスク分析**: ボラティリティ、シャープレシオ、最大ドローダウン
- 📱 **レスポンシブデザイン**: モバイル対応

## 技術スタック

- **フロントエンド**: React 18 + TypeScript
- **ビルドツール**: Vite
- **チャート**: Recharts
- **アイコン**: Lucide React
- **スタイリング**: CSS

## インストール

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# 本番ビルド
npm run build

# ビルド結果をプレビュー
npm run preview
```

## 使い方

### 1. ポートフォリオ作成

1. 初期現金を設定
2. 株式または債券を追加
   - **株式**: シンボル、価格、期待リターン、ボラティリティ、配当利回りを入力
   - **債券**: シンボル、額面、クーポンレート、償還期間を入力
3. 資産配分を確認

### 2. シミュレーション実行

#### 単一シミュレーション

- シミュレーション期間を設定（日数）
- 実行ボタンをクリック
- ポートフォリオ価値の推移、統計情報を確認

#### モンテカルロシミュレーション

- シミュレーション回数と期間を設定
- 実行ボタンをクリック
- パーセンタイル分析、将来の資産価値分布を確認

## 主要機能

### 資産モデル

- **Stock**: 株式クラス
  - 幾何ブラウン運動による価格シミュレーション
  - 配当金の自動計算
  - リスク・リターン分析

- **Bond**: 債券クラス
  - 現在価値法による価格計算
  - クーポン支払い
  - デュレーション計算

### ポートフォリオ管理

- 資産の購入・売却
- リアルタイム総資産価値計算
- 資産配分の可視化
- シャープレシオ、期待リターン、リスクの計算

### シミュレーション

- **単一シミュレーション**: 指定期間のポートフォリオ価値推移を予測
- **モンテカルロシミュレーション**: 複数シナリオで将来の資産価値分布を分析
- チャートによる可視化
